Live Crowd Detection System

Overview

The Live Crowd Detection System is an intelligent computer vision application that monitors crowded environments in real time. It detects people using YOLOv5 deep learning and applies advanced tracking algorithms to estimate crowd density, detect potential stampedes, and alert authorities when abnormal movement is detected.

Key Features

  • Real-time Detection: Uses YOLOv5 to detect persons in video frames instantly.
  • Centroid-based Tracking: Continuously tracks individuals using their movement patterns and positions.
  • Stampede Detection: Monitors crowd density and identifies when occupancy exceeds a threshold (default 85%).
  • Abnormal Speed Alert: Detects high-speed movement patterns indicating possible panic or stampede.
  • Audio Alerts: Plays a warning sound (sound.wav) during danger or overcapacity.
  • SMS Notifications: Sends instant alerts to authorities via Twilio API.

How It Works

The system captures live video feed from a webcam and passes each frame through the YOLOv5 model to identify people. Detected individuals are tracked using a centroid-based tracker to measure movement and estimate speed. If the crowd exceeds the user-defined capacity or movement speed surpasses a threshold, the system automatically:

  • Plays an audible alarm using winsound.
  • Sends a text alert through Twilio to the configured phone number.
  • Highlights abnormal individuals and shows real-time occupancy stats on screen.

Technology Stack

  • Programming Language: Python
  • Deep Learning Model: YOLOv5 (PyTorch)
  • Libraries: OpenCV, NumPy, Twilio REST API
  • Alert System: Audio (winsound) + SMS via Twilio
  • Interface: Flask-based Web Interface with Live Stream

Safety Applications

This system can be deployed in high-footfall areas such as stadiums, railway stations, malls, and event venues to monitor crowd density and automatically alert authorities before panic situations occur. It contributes to improving public safety through real-time AI surveillance.
